개인정보처리방침

문서 버전: 2026-10-23. 운영자: 우주잠자리 Galaxy Lab 소유자. ### 접근과 이용 목적 이 도구는 소유자가 지정한 지시함의 텍스트 파일 내용, 파일 이름·수정 시각·식별자와 실행 결과를 사용합니다. 목적은 소유자가 요청한 AI 작업 수행, 실행 기록 및 결과 보관입니다. 사진·연락처 등 휴대폰 개인 자료는 수집 대상이 아닙니다. ### Google 권한 현재 Google OAuth는 Drive 전체 접근 범위를 사용합니다. 실행 코드는 승인된 지시함을 읽고 별도의 결과 폴더에 새 결과 파일을 만드는 경로로 제한합니다. 이 코드의 경로 제한은 Google 토큰 자체의 권한 제한과 같지 않습니다. 인증 자료가 노출되면 더 넓은 Drive 접근 위험이 있으므로 공개 자료에 포함하지 않습니다. ### AI 서비스로 전달되는 내용 선택된 지시 파일의 텍스트가 소유자의 Codex(OpenAI) 및 Claude(Anthropic) 계정을 통해 해당 서비스로 전달됩니다. 소유자는 지시함에 자신이 해당 서비스에 전달할 권한이 있는 자료만 넣어야 합니다. 연구소 도구는 별도의 범용 AI 모델 학습을 수행하지 않습니다. 서비스 제공자의 처리·보관은 해당 서비스 정책과 실제 계정 설정을 따르며, 이 문서는 제공자의 학습 제외 설정이 검증됐다고 주장하지 않습니다. ### 보관과 공개 작업 지시 사본, 실행 출력과 상세 사용량 장부는 소유자의 Galaxy Linux 작업 폴더에 보관됩니다. 허용된 Markdown 결과, 일별 요약, 학습 기록 및 계정 한도 요약은 소유자의 전용 Drive 결과 폴더에 보관됩니다. 상세 usage.csv는 현재 외부 업로드 대상에서 제외됩니다. 보관 기간 자동 만료와 자동 삭제는 구현하지 않았습니다. 이 공개 소개·정책 문서에는 실제 지시, 결과, 계정 사용량, 폴더 식별자, 인증 자료를 싣지 않습니다. ### 접근 중단과 삭제 요청 소유자는 Google 계정의 제3자 앱 연결 화면에서 앱 접근을 철회할 수 있습니다. 철회는 새 API 접근을 중단하지만 이미 저장된 로컬 파일이나 Drive 결과를 자동 삭제하지 않습니다. 저장 자료 삭제는 소유자가 각 저장 위치에서 직접 수행하거나 별도 승인해야 합니다. 외부 사용자 가입을 받지 않는 개인 도구이므로 공개 문의 양식은 제공하지 않습니다. ### Google 데이터 이용 원칙 Google API로 받은 정보는 공개한 사용자 요청 기능의 제공에만 사용합니다. 광고 판매, 데이터 중개, 범용 AI 모델 학습 목적으로 사용하지 않습니다. Google API Services User Data Policy 및 해당 Limited Use 요구사항을 준수하는 범위에서 운영합니다. 실제 동작이나 이용 목적을 바꾸기 전 문서와 동의를 갱신해야 합니다. 참고: https://developers.google.com/terms/api-services-user-data-policy
